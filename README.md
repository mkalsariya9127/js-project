# ⚡ Vanilla JavaScript Mini Projects & UI Components

A collection of interactive frontend web components and mini-applications created to master JavaScript DOM manipulation, event-driven programming, and asynchronous logic.

---

## ✨ Highlights
- **DOM Manipulation:** Real-time element creation, styling, and event listeners.
- **Form & Input Validation:** Interactive form handlers with instant user feedback.
- **Modular Code:** Clean, readable, and structured JavaScript logic.
- **Responsive Layout:** Styled using modern CSS Flexbox and Grid.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic markup
- **CSS3:** Custom styles, animations, responsive design
- **JavaScript (ES6):** DOM manipulation, functions, event listeners

---

## 🚀 Getting Started
```bash
git clone https://github.com/mkalsariya9127/js-project.git
```
Open `index.html` or `output.html` in any web browser.
